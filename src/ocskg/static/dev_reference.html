Security for AI
类库与工具选型参考。

本页把两个设计文档中提到的安全框架、类库和工具按产品能力归类，方便把 SentinelGraph 的 AI Security 控制面继续扩展为可接入、可治理、可审计的工程实现。

输入/输出护栏 RAG 与 Agent 隐私与脱敏 对抗鲁棒性 对齐训练 选型建议

01 / GUARDRAILS输入与输出安全护栏

用于实现 prompt injection、jailbreak、有害输出、结构化输出和策略化阻断。适合接在 AI Gateway、RAG 编排层或 Agent 编排层之前。

Llama Guard 3

Meta 的输入/输出安全分类模型，适合把“是否违规、是否高风险”抽象成一个独立分类服务。

  • 对应 SentinelGraph：Prompt Gate、Output Gate。
  • 适合：恶意指令、隐私泄露、有害内容和策略分类。
  • 注意：需要模型部署、评测和本地策略映射。
ClassifierInput/Output

NeMo Guardrails

NVIDIA 的可编程护栏框架，用 Colang 定义对话流程、允许路径和阻断规则。

  • 对应 SentinelGraph：策略中心、AI Gateway。
  • 适合：企业客服、Copilot、Agent 对话流约束。
  • 注意：规则维护成本高，适合稳定业务场景。
Policy FlowColang

Guardrails AI

面向 LLM 输出验证的 Python 框架，可做 JSON Schema、字段约束、重试和阻断。

  • 对应 SentinelGraph：结构化输出校验、Agent 调查结果约束。
  • 适合：要求模型返回固定结构或合规字段的业务。
  • 注意：输出验证不能替代输入侧注入检测。
ValidationSchema

LangKit

WhyLabs 的 LLM 监控与文本质量工具，覆盖提示词质量、毒性、相似度和注入相关信号。

  • 对应 SentinelGraph：AI Security Telemetry。
  • 适合：离线扫描、监控指标、风险趋势分析。
  • 注意：更偏观测和特征，不是完整审批流。
MonitoringSignals

02 / RAG + AGENTRAG 与 Agent 执行安全

用于把企业知识库权限、上下文隔离、工具执行审批和沙箱运行落到工程系统里。

E2B Sandbox

面向 AI Agent 的云端沙箱，提供隔离的代码执行环境。

  • 对应 SentinelGraph：Agent Runtime Sandbox。
  • 适合：Python/JS 代码执行器、文件分析、临时工具运行。
  • 注意：高危动作仍应接审批和审计。
SandboxAgent

LangChain

常见 LLM/Agent 编排框架，可在链路中挂接 SentinelGraph 的评估 API、审计和审批。

  • 对应 SentinelGraph：SDK / Gateway 集成。
  • 适合：已有 LangChain Agent 或工具链项目。
  • 注意：工具权限和 RAG 过滤不要只靠 prompt 声明。
OrchestrationAgent

LlamaIndex

RAG 和数据连接框架，可把租户、角色、部门等元数据过滤下沉到检索层。

  • 对应 SentinelGraph：RAG Access Control。
  • 适合：企业知识库、文档检索、索引治理。
  • 注意：必须强制 metadata filter，不能只在模型提示里要求遵守权限。
RAGMetadata Filter

Human-in-the-Loop 审批流

设计文档强调高危工具必须人工确认。工程上可落到工单、SOAR、审批队列或 ChatOps。

  • 对应 SentinelGraph：Agent Tool Guardrails。
  • 适合：发送邮件、写数据库、删除、转账、外部 Webhook。
  • 注意：审批对象应包含工具名、参数、上下文和风险发现。
ApprovalAudit

03 / PRIVACY隐私保护与数据安全

用于处理 PII、Secret、成员推断、模型反演和隐私计算场景。

Microsoft Presidio

PII 检测与匿名化框架，适合在请求发送给模型或第三方服务前做脱敏。

  • 对应 SentinelGraph：Data Protection、Prompt Sanitization。
  • 适合：姓名、邮箱、手机号、证件号、地址等识别和替换。
  • 注意：行业字段和中文实体通常需要自定义 recognizer。
PIIMasking

Opacus

PyTorch 的差分隐私训练库，通过梯度裁剪和噪声降低成员推断风险。

  • 对应 SentinelGraph：模型训练治理参考。
  • 适合：需要训练或微调模型的隐私敏感场景。
  • 注意：会影响模型效果，需要隐私预算管理。
DPPyTorch

TensorFlow Privacy

TensorFlow 生态的差分隐私训练工具。

  • 对应 SentinelGraph：模型训练安全评估。
  • 适合：TensorFlow/Keras 训练栈。
  • 注意：更适合训练阶段，不解决 RAG 运行时越权。
DPTensorFlow

FATE / Flower / PySyft

联邦学习相关框架，让数据尽量留在本地，只交换模型参数或安全计算结果。

  • 对应 SentinelGraph：高敏行业 AI 治理参考。
  • 适合：金融、医疗、跨组织联合建模。
  • 注意：工程复杂度高，通常不是 MVP 第一阶段。
Federated Learning

Microsoft SEAL / Zama Concrete-ML

同态加密和隐私推理工具，适合极高敏数据场景。

  • 对应 SentinelGraph：隐私计算扩展方向。
  • 适合：云端不可见明文的推理或计算。
  • 注意：成本和限制较高，应按场景评估。
FHEEncrypted ML

04 / ROBUSTNESS对抗鲁棒性与攻击评测

用于算法层评测，比如对抗扰动、鲁棒性基准和模型安全测试。

Adversarial Robustness Toolbox

IBM / LF AI & Data 生态的对抗鲁棒性工具箱，支持多种攻击、防御和评测方法。

  • 对应 SentinelGraph：模型安全评测实验室。
  • 适合：CV、NLP、表格模型的对抗测试。
  • 注意：偏模型研发阶段，不是运行时网关。
Adversarial MLEvaluation

CleverHans

对抗样本与鲁棒性研究常用库，适合建立模型安全测试基线。

  • 对应 SentinelGraph：模型上线前评测。
  • 适合：研究型或模型平台团队。
  • 注意：需要和业务模型、数据集、攻击假设绑定。
ResearchRobustness

05 / ALIGNMENT对齐训练与模型治理

用于 RLHF、DPO、PPO、分布式对齐训练等模型研发阶段能力。它们和运行时护栏互补，不应互相替代。

TRL

Hugging Face 的 Transformer Reinforcement Learning 库，支持 DPO、PPO、RLHF 等训练流程。

  • 对应 SentinelGraph：模型治理与安全微调参考。
  • 适合：企业自训或微调安全模型。
  • 注意：训练后仍需要运行时审计和护栏。
DPORLHF

DeepSpeed-Chat / Ray Alignment

大规模分布式对齐训练方向，适合千亿参数级模型训练和强化学习管线。

  • 对应 SentinelGraph：大型模型平台远期能力。
  • 适合：有模型训练基础设施的团队。
  • 注意：不适合作为产品 MVP 的第一依赖。
Distributed Training

06 / SELECTION落地选型建议

MVP 优先级：先做运行时网关、PII/Secret 脱敏、RAG metadata filter、工具审批和审计链。模型训练、联邦学习、同态加密和对抗训练属于后续能力，适合在客户场景明确后分阶段接入。

第一阶段

Presidio + 规则检测 + Llama Guard / NeMo Guardrails + SentinelGraph 审计。

GatewayAuditMVP

第二阶段

接入 LangChain/LlamaIndex 编排，强化 RAG 权限过滤、工具审批和批量扫描。

RAGAgentApproval

第三阶段

引入 ART、CleverHans、TRL、Opacus 等训练和评测工具，服务模型平台团队。

EvaluationTraining

高敏行业扩展

按需评估 FATE、Flower、PySyft、SEAL、Concrete-ML 等隐私计算方案。
